01

Connect your project

Store the anon key in runtime settings, keep privileged keys in editor-local storage, and verify the connection from the setup window.

SupabaseClient.InitializeFromResources();

02

Build gameplay systems

Generate models from your schema, query with typed lambdas, and install backend packs for saves, economy, guilds and more.

.From<Player>("players")
.Where(p => p.score > 1000)
.OrderByDescending(p => p.score)

Honest boundary

What it does not do

  • It does not host your game backend for you.
  • It does not bypass Supabase Row Level Security.
  • It does not treat client-reported economy or scores as trusted.
  • It does not send player data through ShipIt servers.
Unity-native API

Readable C#.
No proxy SDK.

Call your Supabase project directly with async APIs, typed models, cancellation support and errors you can act on.

Typed query builder. Lambda filters with generated models — no SQL strings in gameplay code.
Async with cancellation. Every call supports cancellation tokens and reports actionable server errors.
IL2CPP-safe. No Expression.Compile in query paths, linker protection included, WebGL paths covered.
Token streaming. Proxy AI providers through your own Edge Function with SSE or raw chunk streams.
