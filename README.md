# ShipIt

Official website and public documentation for ShipIt Unity tools and the
Unity Supabase Toolkit.

The toolkit provides Unity-native access to authentication, typed database
queries, realtime channels, storage, live-ops, AI workflows, editor tooling,
and secure game-backend systems built on Supabase.

## Website

- Product overview: `index.html`
- Documentation: `documentation.html`
- Live-Ops Dashboard overview: `live-ops.html`
- Asset Store availability: `store.html`
- Privacy: `privacy.html`

The site is dependency-free, contains no analytics or cookies, and can be
served directly through GitHub Pages.

## Site configuration

Set `assetStoreUrl` in `site-config.js` after the Unity Asset Store listing is
live. Every purchase action on the site reads that single value. The support
address is configured in the same file.
