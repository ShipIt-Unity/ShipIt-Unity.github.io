Amazon Web Services for Unity, including WebGL.

Cognito auth with SRP and MFA · Identity Pools · S3 with multipart uploads · DynamoDB with typed models · Lambda invocation · game systems · an eight-tab editor suite. Pure C# over the AWS REST surfaces — no aws-sdk-net DLLs, no native plugins, IL2CPP/AOT-safe.

Status: private beta. Asset Store listing in progress — email support for early access.

The runtime SDK

  • Auth (Cognito User Pools) — sign-up/confirm, USER_SRP_AUTH (the password never leaves the device), MFA continuation for SMS, TOTP and e-mail OTP, forced-password change, refresh tokens, GlobalSignOut, persistent sessions.
  • Social sign-in — Cognito Hosted UI via OAuth2 + PKCE (Google, Apple, Facebook), with deep-link completion that survives app suspension.
  • Identity Pools — anonymous or authenticated temporary credentials with automatic refresh; every signed call uses scoped STS credentials, never long-lived keys.
  • S3 — upload/download/metadata/delete, listing pagination, presigned GET/PUT URLs, multipart uploads for large files with gap protection and automatic abort, Texture/Sprite/AudioClip loaders.
  • DynamoDB — [Serializable] model marshalling, reserved-word-safe expression builders, Query/Scan pagination, conditional writes, batched writes with unprocessed-retry, transactions, PartiQL, COUNT-only rank queries.
  • Lambda — signed data-plane invokes plus Function URLs (the WebGL path), typed request/response overloads.
  • Signature V4 — a pure-managed signer validated against official AWS example vectors.

Game systems included

Leaderboards with best-wins conditionals and server-authoritative score submission (Node.js Lambda template) · cross-device cloud saves with optimistic concurrency · feature flags with deterministic percentage rollout · analytics events with TTL retention · an offline mutation queue that survives restarts and replays strictly in order.

Provision all backing tables from the editor in one click; scoped IAM policy templates ship alongside.

An editor suite that ends in one green button

Eight tabs: settings wizard, connection checks, pack provisioning with IAM templates, read-only DynamoDB browser, table → C# model generator, configuration doctor (including live bucket-CORS validation), diagnostics — and a live smoke suite that exercises every service against your real account end-to-end, then deletes its own test user. Ship-day verification is a log file.

Security & compatibility

No long-lived keys in clients — ever. Identity Pool roles scope players to their own rows via LeadingKeys; the doctor flags extractable app-client secrets; scoring can run fully server-authoritative through your own Lambda. Ships with link.xml for IL2CPP stripping and a CI release gate enforced by its test suite.

Unity 2022.3 LTS · Mono and IL2CPP · Windows, macOS, Linux, Android, iOS, WebGL · Built-in, URP and HDRP. 155+ automated tests including crypto cross-verification and pinned wire vectors.
