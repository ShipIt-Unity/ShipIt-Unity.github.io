Changelog · latest first

What's new in the Unity Supabase Toolkit.

Every update keeps full C# source, idempotent SQL packs and your project data untouched. The complete engineering changelog ships inside the package as CHANGELOG.md.

Current · August 22, 2026

v1.46.3 — SRP-safe text shader

  • The bundled TextMeshPro distance-field shader now declares separate SubShaders with single-value render-pipeline tags (URP, HDRP) plus an untagged Built-in fallback, so text renders identically in every pipeline and passes modern Asset Store validation.
August 21, 2026

v1.46.2 / v1.46.1 — Validation hardening

  • Fast Enter Play Mode support: all toolkit static state (client singleton, request and realtime inspectors, logger buffers, test transports, editor caches) now resets between Play sessions via RuntimeInitializeOnLoadMethod(SubsystemRegistration); static event subscribers are unregistered automatically.
  • Cleaner sample scenes: demo scenes no longer embed uGUI or Input System component references. The demo runner builds its Canvas, UI panel and EventSystem at runtime, so scenes import with zero missing components in any project.
  • Bundled text shader: the Poppins SDF font material now uses a shader that ships inside the package, so UI text works without importing TMP Essentials.
August 2026

v1.46.0 — Analytics pack (34th pack)

  • New analytics drop-in SQL pack: a batched analytics_events table for DAU, funnels and retention, secured so clients can only insert their own events while dashboards read with the service role.
  • Pairs with AnalyticsService.Track() and auto-flush; indexes on event + time and user + time are included.
  • Every feature service in the toolkit now maps to a SQL pack.
August 2026

v1.45.0 — Production reliability release

  • AOT-safe typed queries: lambda filters no longer use Expression.Compile(), keeping IL2CPP and console targets safe.
  • Resilient auth refresh: transient network failures retry with bounded backoff instead of dropping sessions.
  • Realtime auth lifecycle: sign-in, sign-out and token refresh propagate automatically to private channels.
  • Complete OAuth PKCE: deep-link callbacks, code exchange and legacy token import handled end to end.
  • Truly resumable uploads: TUS locations survive app restarts and ambiguous failures reconcile before retrying.
  • The automated test suite grew to 130 EditMode tests.
July 2026 · current store listing

v1.44.0 — SDK parity and security hardening

  • Auth: persisted-session expiry fixes, CAPTCHA-aware sign-ins, Apple/Google ID-token flows and identity linking.
  • Database: negated filters, OR expressions, culture-invariant dates, offline-cache correctness.
  • Realtime: per-filter channels, join acknowledgements, serialized connects, DELETE payloads delivered.
  • Storage: object listing with prefix/search/pagination/sorting, normalized signed URLs, path-traversal rejection.
  • Security: service-role keys moved to machine-local editor storage, privileged economy/quest/battle-pass mutations became service-role-only RPCs.
Note

Updating an existing project

  • Asset Store buyers: download the new .unitypackage from your Purchases page and re-import; nothing is overwritten outside the Assets/ShipIt/Supabase folder.
  • UPM users: refresh the package in Package Manager or point the manifest at the new tarball.
  • SQL packs are idempotent — re-running them is safe and picks up policy/function improvements.
